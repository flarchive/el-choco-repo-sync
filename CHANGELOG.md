# Changelog

## 0.1.0-beta.1 — 2026-11-21

First local beta for Flarum 2.0.2 and newer 2.x versions allowed by Composer.

- GitHub README synchronization in a protected first-post section or whole-post mode.
- Published release replies with optional prereleases.
- Signed webhooks, persistent jobs, duplicate protection and transient failure retries.
- Manual processing, first-post ID lookup and backup access in the admin panel.
- Normal Flarum publishing permissions and ten retained post backups per mapping.
- English and German interface and documentation.

Erste lokale Beta für Flarum 2.0.2 und neuere von Composer zugelassene 2.x-Versionen.

- GitHub-README im geschützten Startbeitragsbereich oder als vollständigen Beitrag abgleichen.
- Antworten bei veröffentlichten Releases, optional mit Vorabversionen.
- Signierte Webhooks, dauerhafte Aufträge, Schutz gegen doppelte Veröffentlichungen und Wiederholungsversuche bei vorübergehenden Fehlern.
- Manuelle Verarbeitung, automatische Ermittlung der Startbeitrags-ID und Zugriff auf Sicherungen im Adminbereich.
- Normale Flarum-Veröffentlichungsrechte und zehn Beitragssicherungen je Zuordnung.
- Deutsche und englische Oberfläche und Dokumentation.
